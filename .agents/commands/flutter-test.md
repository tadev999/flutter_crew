# /flutter-test Command

Runs the Flutter test suite and analyzes failing tests.

## Actions Executed

1. Runs `flutter test --coverage`.
2. Inspects test failures, diagnoses root cause, and proposes fixes.
3. Summarizes test results and coverage percentage.

## Usage

```text
User: /flutter-test
```
